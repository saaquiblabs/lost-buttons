# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, and keep discussion about the work. Harassment,
insults and personal attacks aren't welcome in issues, pull requests or anywhere else connected to
the project.

Report problems to hello@saaquiblabs.com. Reports are read by the maintainer and kept private.
