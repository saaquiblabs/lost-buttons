# Security

Lost Buttons reads input from mice and sends Back/Forward presses, so it holds two sensitive macOS
permissions (Input Monitoring and Accessibility). Please treat any way to misuse that as a security
problem.

## Reporting

Please don't open a public issue. Report it privately:

- on GitHub: **Security → Report a vulnerability** in this repository, or
- by email: hello@saaquiblabs.com

You'll get a reply within a few days. Once it's fixed and released, we'll credit you in the changelog
unless you'd rather not.

## Supported versions

Only the latest release gets fixes. Upgrade with `brew upgrade lost-buttons`.
